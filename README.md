# Isaac Twin project homepage

Static project homepage with local video assets. No build step is required.

## Publish with GitHub Pages

Upload the contents of this directory to a dedicated website repository. Do not upload the simulation platform repository, datasets, or Sites configuration.

In repository Settings → Pages, choose Deploy from a branch, then main and / (root). The index.html file must be at the repository root.

For a project site named isaac-twin, the URL is https://xinzhenqin.github.io/isaac-twin/ . For an account site, use a repository named YOUR-USERNAME.github.io.

This site is public when published with ordinary GitHub Pages. The previous Sites email allowlist does not transfer. The owner authorized public publication of this showcase and its demonstration videos on 2026-10-02.

All scripts, images and video files use relative same-origin paths and work at either the domain root or a project subpath. No ChatGPT login is required. Mainland China reachability must be tested from the visitor's actual network.
